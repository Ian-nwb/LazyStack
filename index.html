Pick.

Choose a preset or add frameworks one by one: frontends, APIs, full-stack apps, workers, desktop and mobile clients, in any mix.

This page follows one project, acme-platform: a React + Vite client, a FastAPI API it calls, PostgreSQL and Redis, behind Nginx.

Upgrade.

When a release fixes a template, lazystack upgrade pulls the fix into your project with a three-way merge. Your edits stay.

Upgrading ~/projects/acme-platform to LazyStack 2.1.0...
Rendering the old template (npx lazystack@<old version>) and the new one, then merging...

  apps/client/Dockerfile

The CLI.

The same generator in your terminal. A JSON blueprint describes the stack; every command reads it.

CommandWhat it does
npx lazystack initCreate a blueprint from a preset (interactive in a terminal)
validate · plan · doctor · portsCheck a blueprint, preview the tree, check toolchains, find busy ports
hostingSuggest hosting per app; --types compares all eleven
scaffold -c lazystack.jsonGenerate the project (--dry-run to preview)
devStart the stack with the dashboard (--plain for plain logs, --docker for containers)
import · add · applyRead an existing project, add an app, apply an edited blueprint; your code is never overwritten
upgradePull template fixes into a generated project (--dry-run, --from 2.0.0 for older projects)
list · presets · searchBrowse the catalog (--json for scripts)

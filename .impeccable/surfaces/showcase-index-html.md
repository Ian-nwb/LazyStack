# Showcase (showcase/index.html)

Scope: the public LazyStack showcase, one static page deployed to Vercel. Visitor mode: Persuade.
Audience: solo developers starting a side project or prototype. Action: download the desktop app (Linux AppImage, Windows portable EXE); `npx lazystack` is secondary.
Proof: real app screenshots (showcase/assets/screens), and real CLI output generated for this page (file tree, hosting plan, upgrade report, dev dashboard). No invented users, counts or quotes.
Constraints: black, white and zinc only (user-pinned). Previous page kept at showcase/index.legacy.html.
Memorable moment: the lazystack dev dashboard replayed on the poster grid, services lighting in dependency order.

## Direction contract

THESIS: A Swiss International Typographic Style poster system: a visible 12-column module grid, monumental numbers that are the headline, flush-left grotesk, and objective photography that is the real app. Refuses the dark dev-tool template (centred headline, glow, feature-card grid).

OWN-WORLD: #050505 sheet, white type, zinc-800 grid hairlines and ghost modules, zinc-400 captions; one white block per viewport is the action. Self-hosted grotesk (Archivo) at extreme scale contrast; system mono only for real code and terminal output. Ruled full-width rows, never cards. One continuous vertical rule carries the project's life down the page.

STORY: A visitor sees 142 frameworks and the real app, understands they pick a stack and get the whole project, follows one project through pick, generate, run, host and upgrade in real output, then downloads.

FIRST VIEWPORT: Top rule with mark, nav and version. Left six columns: "142" monumental, then "frameworks. Pick yours. Get the whole project." flush left, then the white Download block (Linux / Windows) with npx beneath. Right six columns: the App Stack screenshot bleeding off the right edge, captioned Fig. 1 on the shared baseline. Grid hairlines visible behind everything.

FORM: The Swiss Poster System, position 5 of my ordered list after re-roll 1; seed key dc54ac73. Signature interaction: the dev dashboard replay. Amended at the user's request ("more animations than legacy, eye catching"; no white sheets, all black): a full motion grammar on load and scroll (grid draw, mark draw, 142 count-up with imprint, letter and word blur-rise, zinc block-wipe figures, printed output, cascading rows, lifecycle rule fill, walking lamp on hosting types), every loop finite; raises: continuous lifecycle rule, load-bearing shapes only, ghost cells, shared baselines, one printing process.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

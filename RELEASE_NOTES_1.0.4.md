# LazyStack v1.0.4

This release adds native project generation with an optional unified workspace, a tested FastAPI API-service profile, connected OpenAPI TypeScript client generation, and service/network architecture diagrams with SVG and Markdown export. Generated-project CI now checks representative JavaScript/TypeScript, Python, Go, Rust, Java, Kotlin, and PHP projects.

## Downloads

- Linux x64: `LazyStack-1.0.4.AppImage`
- Windows x64: `LazyStack 1.0.4.exe` (portable)

macOS packages are not included.

## Deferred to v1.0.5

gRPC/protobuf contracts, event schemas and broker wiring, configurable service-to-service authentication, the opt-in observability profile, and broader framework starter coverage are tracked in `ROADMAP-1.0.5.md`.

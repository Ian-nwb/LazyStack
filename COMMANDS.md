# LazyStack — Complete Command Reference

A single reference sheet for running, building, shipping LazyStack, and running generated monorepos.

---

## 1. Local Development (Live Reload)

Runs the desktop application with live hot-module replacement (HMR):

```bash
npm run dev
```

---

## 2. Production Testing Locally

Compile and run the optimized production build on your machine:

```bash
# Step 1: Compile the production bundle
npm run build

# Step 2: Launch the compiled Electron application
npm start
```

Or run the pre-packaged standalone binary directly (no Node needed):

```bash
./release/linux-unpacked/lazystack
```

---

## 3. Shipping & Packaging Distributables

Package standalone production installers into the `release/` directory:

### Linux (AppImage & deb)
```bash
npm run dist:linux
```
> **Output in `release/`:**
> - `LazyStack-1.0.0.AppImage` (Universal portable Linux binary)
> - `LazyStack-1.0.0.deb` (Debian / Ubuntu installer)

### Windows (.exe Installer & Portable)
```bash
npm run dist:win
```
> **Output in `release/`:**
> - `LazyStack Setup 1.0.0.exe` (NSIS Windows installer)
> - `LazyStack 1.0.0.exe` (Portable executable)

### macOS (.dmg)
```bash
npm run dist:mac
```
> **Output in `release/`:**
> - `LazyStack-1.0.0.dmg` (Apple disk image installer)

### Unpacked Directory Only (Fast verification)
```bash
npm run pack
```
> **Output:** `release/linux-unpacked/`

---

## 4. Running a Monorepo Generated by LazyStack

When you generate a project using LazyStack (e.g. `my-project/`), run it using its one-command launcher:

### On Linux / macOS (POSIX Bash)
```bash
cd my-project
chmod +x scripts/dev.sh
./scripts/dev.sh
```

### On Windows (PowerShell)
```powershell
cd my-project
.\scripts\dev.ps1
```

### Useful Commands Inside a Generated Project
```bash
# View live streaming logs across all containers
docker compose -f infra/docker-compose.yml logs -f

# Run automated integration health checks
./tests/healthcheck.sh

# Stop all services and containers
docker compose -f infra/docker-compose.yml down

# Reset database volumes and restart clean
docker compose -f infra/docker-compose.yml down -v
./scripts/dev.sh
```

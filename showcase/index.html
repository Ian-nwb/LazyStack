LazyStack lets you choose languages, frameworks, databases, service connections, testing tools, and an architecture layout. It then writes the project structure and the configuration around it.

Features 10 capabilities

One blueprint, every layer.

Mix application roles
Generate frontend clients, backend services, full-stack apps, workers, and desktop or mobile clients in the same project.
Broad catalog
Start from an established framework or a plain language runtime template: React, Vue, Angular, Solid, Qwik, HTMX, Lit, Kotlin/JS, SwiftUI, Reflex, NiceGUI, Anvil, Go, Rust, Java and many more.
Architecture layouts
Pick a preset, or set your own root directories, extra folders, and per-app paths.
Polyglot layout
Browser clients go to frontend/clients/, API services to backend/services/, workers to backend/workers/, and deployment files to deploy/.
Service connections
Configure API URLs, environment variable names, health checks, and startup dependencies between services.
Database setup
Add self-hosted databases or managed cloud providers, set per-service database scope, and get local credentials generated into .env.
Database web UIs
Attach an admin UI to a database instance: Adminer, pgAdmin, Prisma Studio, phpMyAdmin, Mongo Express, or Redis Commander, matched to the engine. Prisma Studio gets a generated local launch command.
Testing tools
Choose tools per app, grouped by purpose. They are opt-in, so no test runner lands in a service that did not ask for one.
Infrastructure output
Docker Compose, optional Nginx or Apache routing, environment files, scripts, shared packages, and starter documentation.
Blueprints + CLI
Export a JSON blueprint, then scaffold it from the command line without opening the desktop app.
Layouts 10 architectures

Choose where things live.

Every layout is a starting point. The Polyglot layout splits a project by role, so clients, services, workers, and deployment files each get their own root.

Polyglot layout, illustrative
my-app/
├── frontend/
│   └── clients/     browser clients
├── backend/
│   ├── services/    API services
│   └── workers/     background workers
├── deploy/          deployment files
├── .env             generated database credentials (keep private)
└── .env.example     safe placeholders

CLI No window required

Scaffold from the terminal.

Build the CLI once, list what it knows, then export a blueprint and scaffold it. --out is the parent directory where the generated project will be created.

Explore
npm run build:cli
npm run cli -- help
npm run cli -- list
npm run cli -- presets
Export a blueprint, then scaffold it
npm run cli -- export --preset modern-mern --name my-app --out lazystack.json
npm run cli -- scaffold --config lazystack.json --out ./generated
Or scaffold straight from a preset
npm run cli -- scaffold --preset fastapi-react --name my-api --out ./generated

Before you run stacks

  • Docker Engine or Docker Desktop with Docker Compose, to run generated container stacks.
  • The runtime or toolchain that the templates you select require.
  • Node.js 20+ and npm 10+, only if you run or build LazyStack from source.

Run from source

Dev mode
git clone https://github.com/Ian-nwb/LazyStack.git
cd LazyStack
npm install
npm run dev
Desktop app
npm run build
npm start

Build the packages yourself

Linux AppImage + Windows portable EXE
npm run dist:linux    # release/1.0.3/LazyStack-1.0.3.AppImage
npm run dist:win      # release/1.0.3/LazyStack 1.0.3.exe
npm run dist:release  # build both targets
